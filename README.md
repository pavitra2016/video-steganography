# 🎥 Video Steganography using Fake DNA & Complex Frames

## 📌 Description
This project hides secret data inside a video using advanced techniques:
- LSB (Least Significant Bit)
- DNA Encoding
- Fake DNA for added security
- Complex Frame Selection

## ⚙️ Technologies Used
- Python
- Flask
- OpenCV
- NumPy

## 🚀 How to Run
1. Clone the repository
2. Install dependencies:
   pip install flask opencv-python numpy
3. Run the application:
   python run.py
4. Open in browser:
   http://127.0.0.1:5000/

## 🔐 Features
- Secure data hiding
- No visible video distortion
- Multi-layer security system

## 📊 Output
- Stego video generated
- Secret message successfully retrieved
